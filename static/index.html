传染病暴发调查与接触网络

使用浏览器或 curl 调用 JSON API。检验样本按批次和病例关联：初筛阳性进入复核，复核阳性才确认病例；复核阴性或样本失效时病例保持原诊断。

常用接口

GET  /health
GET  /api/<kind>                     # cases / contacts / batches / samples
POST /api/<kind>
GET  /api/entities/<id>
POST /api/entities/<id>/actions     # 初筛 screen_positive/screen_negative
                                     # 复核 review_positive/review_negative
                                     # 失效 mark_invalid（需 reason）
POST /api/samples/<id>/recollect    # 失效样本重采
GET  /api/batches/<id>/progress     # 批次进度
GET  /api/lab/board                 # 检验室看板
